# Suno 模块化风格设计

## 意图

把现有 Suno skill 从“规则密集的固定创作体系”改成“理解用户审美、按单曲自由选风格的轻量助手”。嘻哈、放克、雷鬼、朋克、R&B、爵士、电子、Grunge、原声流行和自由混搭一律平等；《I'm Yours》式阳光、松弛、有律动的原声流行只是可选方向之一。

## 核心设计

- **长期审美底色：**自然、可信、有生命力；人声有性格但不过度炫技；编曲有呼吸和层次；节奏避免机械单调；每首歌有一个记忆点；允许意外但不故意怪异。萨克斯不默认使用，大提琴只在确实需要悲凉感时考虑。
- **单曲临时方向：**核心感觉、风格或混搭、人声角色、自由程度、最多两个明确禁区。未指定的信息由歌曲本身决定。
- **自由度：**稳妥、开放（默认）、实验。
- **按需输出：**只要提示词时不改歌词；只要歌词时不附带整套教学；完整创作才输出歌名、音乐提示词和结构化歌词；修改现有作品只改用户指出的部分。

## 约束降级

三段副歌、Bridge、Solo、固定字数、固定留白数、反常识转折、身份卡和双歌词版本都改为按需工具。继续保留风格框单段、平台字符上限、避免直接写艺术家姓名、明显咬字风险和一次只调一个变量等真正有用的限制。

## 文件影响

- `SKILL.md`：重写为短小的核心工作流和按需参考导航。
- `USAGE.md`：改成面向用户的轻量使用方式。
- `reference/` 与 `templates/`：保留，只有相关任务才读取。

## 验收标准

- 嘻哈、放克和松弛原声流行不会被拉回同一种民谣结构或固定声线。
- 只要提示词时，不输出身份卡、滑杆、双版本歌词等额外内容。
- 默认禁区最多两个，且没有默认流派、声线、配器或结构。
- `SKILL.md` 明显缩短，并直接说明各参考资料何时读取。
